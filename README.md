# Starwake

A procedural space exploration game built with three.js. Everything is in a single `index.html`; open it in a browser or serve the folder with any static server. Best on a computer with a mouse and keyboard.

You fly a light courier out of the Aurel system into an endless, seeded galaxy:

- **Explore**: every star system is generated from its galaxy coordinates, with planets (rocky, gas giants with rings, ice, lava, ocean, desert, toxic), moons, asteroid fields, derelicts, anomalies and stations.
- **Mine**: shoot asteroids to break them into iron, ice, crystal and exotic matter, then sell the ore at stations.
- **Scan and salvage**: survey planets and study rifts for credits, and salvage wrecks for loot and lore. Some wrecks are traps.
- **Fight**: pirate packs grow tougher the farther you travel from home. Pirate nests have turrets and spawn raiders.
- **Upgrade**: eleven ship systems (lasers, capacitors, hull, shields, thrusters, cargo, tractor field, jump drive, fuel tank, missile rack, scanner). Higher-tech stations stock better parts.
- **Contracts**: bounties, surveys, ore deliveries and nest strikes from station boards.
- **Goal**: recover the eight Precursor relics hidden across the outer systems. Station brokers sell leads.

Progress saves automatically in your browser.

## Controls

| Action | Keys |
| --- | --- |
| Steer | Mouse (click to capture it) or arrow keys |
| Fire lasers / missile | Left click or Space / right click or G |
| Throttle | W / S, X to stop, or the scroll wheel |
| Strafe / roll | A D / Q E |
| Boost / cruise drive | Shift / C |
| Interact, dock, scan, salvage | F (hold for scans) |
| Cycle target | Tab |
| Galaxy map / log / sound | M / Esc / N |
